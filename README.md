# Jumpster

Jumpster is a small 2D game I made using Godot. It has a little character, grassy ground, and a tiny box like obstacle to jump over.

It's a simple game, but it was a fun way for me to try out game development and learn by building something playable.

## Play the Game

[Jumpster](https://samiia.itch.io/jumpster)

## Controls

**W / A / S / D** — Move around

## Built With

Godot

## Run Locally

1. Clone or download this repository.
2. Open Godot.
3. Click Import and select the project's project.godot file.
4. Run the project.
